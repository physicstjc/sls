PROJECTILE PHYSICS LAB

Learn how motion in two dimensions builds on one-dimensional equations of motion.

Lesson: one dimension vs two

In one-dimensional motion, an object moves along one axis, so one set of signed quantities describes its displacement, velocity and acceleration. In two-dimensional motion, motion happens along two perpendicular axes. Resolve the initial velocity into components, then solve each axis separately; both components share the same elapsed time.

1D: one axis

Use the signed values along the direction of motion. For constant acceleration, the four equations are:

  • \(v = u + at\)
  • \(v^2 = u^2 + 2as\)
  • \(s = \frac{1}{2}(u + v)t\)
  • \(s = ut + \frac{1}{2}at^2\)

2D: two independent axes

For a projectile (ignoring air resistance), horizontal acceleration is zero and vertical acceleration is gravity:

  • \(a_x = 0\)
  • \(a_y = -g\)
  • \(u_x = u\cos\theta\)
  • \(u_y = u\sin\theta\)

The same four equations work on each axis. Substitute the matching components:

Horizontal (x) Vertical (y)
\(v_x = u_x + a_xt\) \(v_y = u_y + a_yt\)
\(v_x^2 = u_x^2 + 2a_xs_x\) \(v_y^2 = u_y^2 + 2a_ys_y\)
\(s_x = \frac{1}{2}(u_x + v_x)t\) \(s_y = \frac{1}{2}(u_y + v_y)t\)
\(s_x = u_xt + \frac{1}{2}a_xt^2\) \(s_y = u_yt + \frac{1}{2}a_yt^2\)

Both axes use the same time. For a projectile, \(a_x = 0\) while \(a_y = -g\).

Worked example

Launch at \(10\,\mathrm{m/s}\) and \(37^\circ\) above horizontal. Use \(\sin 37^\circ \approx 0.6\), \(\cos 37^\circ \approx 0.8\) and \(g = 9.81\,\mathrm{m/s^2}\).

Resolve velocity first: \(u_x = 10(0.8) = 8.0\,\mathrm{m/s}\) and \(u_y = 10(0.6) = 6.0\,\mathrm{m/s}\). Find the displacement after \(t = 2\,\mathrm{s}\).

\(v_x = 8 + 0(2)\)

\(v_y = u_y + a_yt\)

\(v_y = 6 + (-9.81)(2)\)

\(v_x^2 = u_x^2 + 2a_xs_x\)

\(v_x^2 = 8^2 + 2(0)s_x\)

\(v_y^2 = u_y^2 + 2a_ys_y\)

\(v_y^2 = 6^2 + 2(-9.81)s_y\)

\(s_x = \frac{1}{2}(u_x + v_x)t\)

\(s_x = \frac{1}{2}(8 + v_x)(2)\)

\(s_y = \frac{1}{2}(u_y + v_y)t\)

\(s_y = \frac{1}{2}(6 + v_y)(2)\)
Used — horizontal displacement

\(s_x = u_xt + \frac{1}{2}a_xt^2\)

\(s_x = 8(2) + \frac{1}{2}(0)(2^2)\)

\(s_x = 16\,\mathrm{m}\)

 Used — vertical displacement

\(s_y = u_yt + \frac{1}{2}a_yt^2\)

\(s_y = 6(2) + \frac{1}{2}(-9.81)(2^2)\)

\(s_y = -7.6\,\mathrm{m}\)

After 2 s, the projectile is 16 m horizontally from the launch point and 7.6 m below its launch height.

All answers are given to 2 significant figures; intermediate values are kept unrounded.
